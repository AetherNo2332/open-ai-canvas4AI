本文件保留第一阶段记录。当前 schema 45 / 协议 v3 及统一配置验收见 [Agent Orchestrator 验收](agent-orchestrator-acceptance.md)。

验收日期：2026-10-02（Asia/Shanghai）。源码基线 canary `8ca7b95e`，新增本地调度实现，不推送远程。运行端口 3004；3000、3002、3003 未改动。Pi SDK 0.87.1、会话格式 3、内部协议 v2、数据库 schema 44。

## 实现和环境

4 个短时调度槽，64 驻留准入上限；独立 Pi 生命周期，事件唤醒、5 秒恢复、45/15 秒租约与 epoch fencing。Go 异步工具先保存幂等操作，工具回执沿用原业务事务。运行详情采用一致快照，防止并发水位误读。隔离 PostgreSQL、Redis、后端卷和凭据；Redis 使用独立密码。Go worker、渠道和管理员运行时策略设为 16；只调用内部可控模型桩，无真实收费调用。

## 3004 端到端结果

- 登录 Cookie、画布读写、聊天、读取工具和审批写入通过真实 API 及 Nginx，未调用模拟前端。
- 16 个不同会话、4 个画布：阻塞模型桩，确认全部 16 次请求到达、活动峰值 16，才统一释放；全部完成。请求在等待期间不保留调度槽，否则 4 槽无法启动第 5–16 个请求。
- 实测调度槽峰值 4。15 秒心跳采样中可见 4 个短时恢复/控制 RPC；该采样不是等待模型占槽。容量计数含正在领取的预留名额，因此可短暂显示 20，实际模型会话数为 16。
- 4 个会话等待审批时，其余 12 个会话完成。Agent 停止期间批准一个会话，Go 保存写入与回执；启动后该会话完成，节点数为 1，其他三个仍等待。随后拒绝三个会话并终结。审批/副作用恢复耗时 41.45 秒，包含租约等待。
- 模型请求在途时重启 Agent：请求数始终 1，重启至完成 51.12 秒（脚本固定等待 50 秒让旧租约过期）；释放响应后 0.59 秒完成。进程从内部游标 0 重放已有事件并恢复原任务。
- 公共 SSE：4 个递增事件，从游标 3 续传，仅返回后续 1 个事件。内部消费端另有真实本地 HTTP SSE 断线/重复序号测试；通知缺失由恢复扫描测试覆盖。

## 故障点覆盖

| 中断/重放边界 | 验证方式 |
| --- | --- |
| 模型任务创建后 | 3004 实际 Agent 进程重启，模型请求 count=1 |
| 检查点提交后 | PiCheckpointSequenceAndIdempotency、SDK durable branch 恢复测试 |
| 工具批次准入后 | PiToolBatchReplaySafety、新增 durable tool admission + 同 owner epoch 接管测试 |
| 工具副作用完成后 | Agent 停止时 Go 写入与回执，恢复后节点仍为 1；receipt replay 单测 |
| 审批通过后 | 3004 停止 Agent 后批准，其他审批保持等待，恢复完成 |
| 压缩提交前 | PiContextCompactionRecoversAfterLeaseTakeoverWithoutNewCharge、SDK compaction resume 测试 |

后三类事务/SDK测试与实际进程中断分别列出，未对所有六个边界逐一执行 Go/PG 容器硬杀。旧 epoch 端到端测试断言工具推进被拒绝且 revision、callIndex、transcript 和 operation 数不变；并发接管竞态仍不是长期压力验收。

## 迁移和回退

SQLite 自动测试保留历史运行/消息/事件。另将 PostgreSQL schema 43 备份恢复到独立验证数据库，植入历史运行、消息、事件和 Pi 树，再迁移 44：结果 `44|9|1|1|1`（版本、原 revision、事件数、消息数、Pi 条目数），历史保持。

保留 `.local/baseline/pre-migration43.dump`（初建隔离空库基线）、`pre-migration43-history.dump`（迁移验证数据）、schema 44 当前数据备份，以及 `canvas-event-backend/agent/web:baseline-8ca7b95` 镜像。43 备份恢复已验证；旧 Go/Agent 镜像用原 canary 源码编译，生产镜像未删除。当前验收数据只能用配套 schema 44 程序恢复。恢复 43 数据后才可叠加 rollback Compose。

## 边界与待确认

4 槽消除了等待整轮占槽造成的排队，64 驻留上限及真实模型渠道/资源容量仍可能排队。outbox 暂不自动裁剪，全局计数行会串行事件提交，需要监控长期吞吐。没有执行全仓库 `go test ./...`；执行了相关包及 PG 专项。浏览器明暗主题、移动端和 UI 手工流程尚待确认，API 验收不代替浏览器验收。
