影策把对话创作、画布、短剧制作和电商素材制作放在一个工作区。第一次使用，先选择与你身份对应的入口。

## 我是普通用户

从 [快速开始](./user-guide/getting-started.mdx) 完成第一次创作，再按任务选择：

| 我想做什么 | 阅读指南 |
| --- | --- |
| 对话写内容、生成图片或视频 | [首页创作与生成工具](./user-guide/creation.mdx) |
| 组织参考图、提示词和作品 | [画布与节点](./user-guide/canvas.mdx) |
| 改图、提取视频素材、增强画质或生成音频 | [图片、视频与音频工具](./user-guide/media-tools.mdx) |
| 请 AI 帮忙操作画布 | [Agent 助手与记忆](./user-guide/agent.mdx) |
| 摆机位、做预演或剪辑 | [预演与视频编辑](./user-guide/previs-editor.mdx) |
| 把故事制作成短剧 | [短剧制作](./user-guide/short-drama.mdx) |
| 制作商品图片和营销素材 | [电商创作](./user-guide/ecommerce.mdx) |
| 找作品、整理素材、处理任务 | [素材与任务](./user-guide/assets-tasks.mdx) |

## 我是管理员

从 [管理员指南](./admin-guide/index.mdx) 开始。后台负责站点公共配置；个人模型偏好与个人渠道仍在用户设置中管理。

- [首次配置与功能开放](./admin-guide/getting-started.mdx)：让用户能登录、选模型并完成一次生成。
- [模型与渠道](./admin-guide/models-channels.mdx)：上游服务、前台模型、能力与价格。
- [用户、积分与支付](./admin-guide/users-billing.mdx)：账号、分组、充值、兑换与奖励。
- [创作能力与扩展](./admin-guide/creation-extensions.mdx)：工具、模板、姿势、Agent、插件和技能。
- [电商配置](./admin-guide/ecommerce.mdx)：电商模型、知识、技能与品类。
- [系统设置与存储](./admin-guide/system-settings.mdx)：外观、访问、邮件、存储及资源限制。
- [运营、日志与问题处理](./admin-guide/operations.mdx)：请求、反馈、公告和资源问题。
- [部署、更新与回退](./admin-guide/deployment.mdx)：应用更新和文档更新。

## 版本与可见范围

本指南按仓库当前页面和菜单编写。你使用的站点可能尚未部署相同版本，或由管理员关闭了部分功能。入口未显示时先核对权限、功能开放和站点版本；文档更新不代表功能已在所有实例上线。

开发与运维资料继续保留在技术专题中。指南里的平台路径用于定位页面；无需理解接口或部署参数即可完成普通创作。
