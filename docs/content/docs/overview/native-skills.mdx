---
title: 转换与安装 Native 技能
description: 用 Codex 等编程助手将已有技能适配为影策云端 Agent 可用的技能包
---

技能库工具栏的「技能转换指南」和「安装技能」弹窗中的「查看 Native 技能转换指南」共用一份界面内文档，包含可复制给 Codex、Claude Code 等编程助手的转换提示词。阅读指南和复制提示词不会上传文件或提交生成任务。

## 转换流程

1. 把原技能包解压到单独的工作目录，让编程助手读取入口、参考资料和脚本。保留原包，输出到新目录。
2. 在影策指南中复制转换提示词，附上原包位置。要求助手分别处理标准包结构、引用路径、项目保存方式和外部工具依赖。
3. 查看转换说明，确认保留的专业方法、被替换的本地操作、尚未接入的能力，以及需要实际运行验证的部分。
4. 多个技能保留各自目录后整体压为一个 ZIP，从「安装技能 → ZIP 技能包」一次上传；预览识别到的技能名称和数量后统一安装。单技能 ZIP 与 Markdown 导入仍可使用。

## 标准结构与云端能力

一个技能目录以 `SKILL.md` 为入口，YAML frontmatter 至少包含 `name` 和 `description`。`references/` 保存按需读取的方法资料，`assets/` 保存必要资源。影策可读取 `metadata.version` 作为版本标签。标准结构可参考 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

```text
my-skill.zip
├── SKILL.md
└── references/
    └── workflow.md
```

多个技能可以采用下列合集结构，外面有一层项目目录也可以。每个技能的资料放在自身目录内，不需要逐个压包或逐个上传：

```text
my-collection.zip
└── skills/
    ├── story-router/
    │   ├── SKILL.md
    │   └── references/
    │       └── workflow.md
    └── character-design/
        └── SKILL.md
```

```yaml
---
name: my-skill
description: 说明适用任务和交付结果。
metadata:
  version: "1.0.0"
---
```

包格式校验通过后，还需要核对执行步骤是否适合影策云端：

| 原技能依赖 | 适配方式 |
| --- | --- |
| 当前技能的参考资料 | 按本轮技能目录给出的 location 定位，同包拼接 references 路径 |
| 其他技能的相对路径 | 先定位本轮已选目标技能，再读取其包内文件；不能猜目录名或直接传 `../` |
| 本地工程文件、成果登记与检查点 | 使用画布文本节点保存，保留来源、版本、确认状态并回读核对 |
| 实际拆镜 | 使用 script 剧情节点、连接的风格/要求文本及服务端 storyboard 工具 |
| 图片、视频、角色生产 | 使用实际可用的媒体和角色工具，遵循报价、预算及审批 |
| 在途拆镜或媒体任务 | 依赖结果时使用 wait_generations，在同一运行的下一模型步骤接收通知并回读结果 |
| 终端、PowerShell、Python、本地 SQLite 或 OCR | 不能仅靠上传脚本获得这些能力；缺少工具或外部服务时明确说明不可用 |

native `read` 只读取本轮已选技能包中的 Markdown、TXT 和 JSON，不提供任意磁盘访问或脚本执行。`allowed-tools` 等声明不扩大云端工具权限。来源包中的脚本可以保留，但不能宣称已经执行或已经接入外部知识库。

## 导入后验收

- 单技能目录包含 `SKILL.md`；合集内可有多个技能目录，最多 64 个技能、合计 512 个文件，压缩和解压后均不超过 20MB。直接压缩这些目录，不要只包含一批嵌套 ZIP。
- 安装前可预览名称、简介、版本及文件数；目录外的说明或安装器不会自动执行，也不会作为某个技能的资料导入。合集内重名或某一项无效时不安装；安装记录在同一事务里保存，已有同名技能不覆盖。
- 核对名称、简介和公开状态，在 Agent 技能选择中加入目标技能及其依赖。旧对话更新技能后重新选择，再启动新一轮，以更新冻结的技能版本。
- 用小任务确认参考文件可读、成果确实保存到画布、异步生成完成后能继续。`submitted` 只表示任务入队。
- 无法执行的外部步骤应明确报告；静态检查、技能安装成功和真实创作运行通过是不同的验收结果。
