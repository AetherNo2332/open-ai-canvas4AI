---
title: 电商创作
description: 以真实商品资料制作主图、详情图、SKU 和营销视觉素材
---

入口：左侧电商（`/ecommerce`），需管理员开放并配置电商模型。

## 准备商品资料

准备清晰商品图，以及确认过的颜色、规格、材质、尺寸、包装、品牌和卖点。告诉系统哪些细节禁止修改，例如 Logo、接口位置或配件数量。

尺寸图需要真实尺寸，材质图需要已确认材质，包装图需要包装资料；不要让模型猜测这些事实。三视图尽量提供多个真实角度。

## 从商品到作品

1. 新建或继续一轮创作，上传商品图并描述目标。
2. 选择用途、平台、目标人群、画幅和相关选项。
3. 检查商品事实确认区域，补全缺失资料并纠正识别错误。
4. 查看方向与图片计划，核对每张图的用途、文案、参考和构图要求。
5. 确认生成配置、数量和费用后开始制作。
6. 在「作品」中逐张核对商品外观、文字、尺寸和配件，再下载或继续修改。

## 按用途填写重点

| 用途 | 应重点提供 / 核对 |
| --- | --- |
| 主图、副图、白底图 | 主体完整、颜色准确、背景与用途一致 |
| SKU 图 | 每个 SKU 的名称、颜色、规格及对应参考图 |
| 详情页、整套图片 | 真实卖点、场景、细节、规格与包装，避免多张重复 |
| 场景、卖点、功能图 | 真实使用情境和能够证实的效果 |
| 尺寸、三视图、材质、包装 | 明确数据、真实角度、结构和配件数量 |
| 海报、社交、营销、A+ | 品牌、受众、活动事实、文案和页面用途 |

生成结果仍需人工复核。平台规则可能变化，文档不把生成成功当作符合电商平台审核要求。

## 修改、续做与商品视频

修改时说清对象和范围，例如「只换背景，杯身颜色、Logo 和把手不变」。使用当前轮次继续创作，可以保留已有商品上下文；核对引用是否仍是目标商品。

若站点开放视频能力，可从作品上的「做成视频」或视频入口继续，以图片作为参考后重新设置视频参数。它会创建视频任务，不是将静态图片直接变成免费成片。

## 出错时

提交剩余图片前先核对已完成数量；部分失败时不要默认整套都失败。商品事实错误应先改资料或计划，再重新生成受影响图片。管理员管理的是公共知识与模型，普通用户管理自己的商品输入和作品。
