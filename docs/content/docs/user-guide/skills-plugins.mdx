## 技能与插件有什么区别

技能是给助手使用的方法和工作说明，例如如何规划镜头。插件为平台增加工具、协议或界面能力。安装技能不会自动获得新的模型额度；安装插件也不代表它需要的外部服务已配置完成。

## 使用技能库

入口：左侧技能库（`/skills`）。

1. 在发现页搜索、查看技能说明，判断用途是否匹配。
2. 加入个人技能库后，在助手输入区用 `/` 选择该技能。
3. 提供技能需要的材料并描述目标，再开始对话。
4. 需要修改自己可编辑的技能时进入编辑页，核对内容后保存。

导入技能时使用页面支持的 Markdown、ZIP 或仓库入口。合集预览可能包含多个技能，先检查名称和数量再确认；无效条目应按错误提示修正，不能把导入失败当成安装完成。

## 使用插件中心

入口：左侧插件中心（`/plugins`），需站点开放。

1. 查看插件详情、用途、权限和配置要求。
2. 按页面提供的安装或启用操作完成设置。
3. 配置需要的服务，再回到对应工具检查是否可用。
4. 更新前核对版本与依赖；停用后检查依赖它的创作入口是否仍能工作。

用户能管理哪些插件由平台权限决定。站点级插件、支付服务与公共模型协议由管理员管理，不在个人设置中替全站修改。

## Eagle 素材

入口：插件中心的 Eagle 页面（`/plugins/eagle`），也可从素材页菜单进入。

1. 按页面提示启动并连接本机 Eagle 服务。
2. 确认素材库可读取，浏览或选择目标素材。
3. 按可用操作导入或引用，确认平台中能预览后再用于生成。

本机应用未启动、连接地址不可达或浏览器访问受限时，先恢复连接。另一个设备不能自动访问你电脑上的 Eagle 素材库。

## RunningHub 与其他扩展

RunningHub 插件启用后，个人设置才显示对应配置。填写服务地址、凭据与工作流等页面要求，再检查工作流是否适配当前任务。缺少配置时先修正连接，不反复提交生成。

扩展失败可在 [诊断与反馈](./troubleshooting.mdx) 中记录插件名称、版本、操作步骤和错误提示。
