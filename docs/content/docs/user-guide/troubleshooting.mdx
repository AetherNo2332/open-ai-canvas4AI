## 先按现象处理

| 问题 | 先检查 | 下一步 |
| --- | --- | --- |
| 找不到功能入口 | 是否登录、是否属于管理员功能、站点是否开放 | 核对版本，联系管理员 |
| 模型列表为空 | 系统模型是否可用，个人渠道是否配置成功 | 阅读账户设置，不反复刷新提交 |
| 参数不可选 | 当前模型支持的能力 | 换可用参数或模型 |
| 一直排队 | 是否等待审批、执行器在线、活动任务是否过多 | 保留原任务编号联系管理员 |
| 连接中断 | 原任务是否仍运行 | 重新获取状态，避免重发 |
| 生成完成但保存失败 | 是否有重新保存入口、存储是否可用 | 优先恢复已有作品 |
| 图片或视频打不开 | 重新打开任务或素材后是否恢复 | 报告资源和任务编号 |
| 提示保存仅在本地 | 网络和服务端保存状态 | 恢复同步后再关闭页面 |
| 无法删除素材 | 是否被项目或画布引用 | 查看引用来源后处理 |
| 付款后没到账 | 原订单状态、余额和权益记录 | 提供订单编号核对，先不重复付款 |
| 助手离线 | 是否明确提示执行器不可用 | 联系管理员，勿重建大量对话 |

## 如何提交有效反馈

入口：顶部「反馈」；历史记录在个人设置的反馈分类。

1. 说明从哪个页面开始、执行了哪些步骤。
2. 写清预期结果和实际结果，不只写“不能用”。
3. 附发生时间、任务或订单编号、模型名称和可见错误。
4. 必要时添加截图；裁去密钥、Cookie、验证码和无关私人资料。
5. 需要进一步排查时，在设置的诊断分类导出诊断包，检查后提供给可信管理员。

反馈示例：「在图片工具选择某模型，上传一张参考图后提交；任务编号……，约在……显示保存失败，预览仍能打开。希望恢复原作品，不重新生成。」

## 公告与文档版本

顶部公告入口可查看站点通知；首页可能展示常驻通知。升级后先读公告中的影响范围，再检查功能入口。

文档站可以独立更新。文档描述与当前站点不一致时，向管理员提供页面地址和站点版本，确认是否尚未升级。
