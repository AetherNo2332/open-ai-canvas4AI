## 打开积分中心

点击顶部积分或账户中的购买入口。积分中心以弹窗展示；`/wallet` 会打开相应弹窗并回到首页。站点关闭积分后，仍可能提供存储商品，具体以可见选项为准。

## 充值与购买存储

1. 选择商品分类，区分积分和存储空间。
2. 查看商品数量、期限、价格及支付方式。
3. 创建订单，按提示完成付款。
4. 返回平台确认订单状态，再核对余额或存储权益。

支付页关闭不代表订单失败，付款成功截图也不能替代平台到账记录。状态不确定时先查询原订单，避免重复付款。

## 兑换码与积分记录

在兑换页输入获得的兑换码，提交后检查提示和余额变化。无效、过期或已使用时，保留提示并联系发放方，不要反复尝试同一码。

积分记录用于核对充值、赠送、使用及调整等变化。可用余额与被任务占用的额度可能不同；生成失败是否返还、何时返还，以最终账务记录为准。

遇到异常时准备任务或订单编号、时间、预期变化与实际变化，通过反馈联系管理员，不公开完整支付凭据。

## 签到和注册赠送

管理员启用后，侧栏可出现签到入口。按提示完成签到并核对记录。赠送额度、领取条件和日期规则由站点配置，不能把其他站点的规则视为本站承诺。

## 推广中心

入口：账户提供的推广中心（`/referral`）。

1. 复制自己的邀请链接或推广码。
2. 让新用户通过正确链接注册。
3. 查看邀请与返佣记录；页面显示当前比例和收益。

当前页面说明返佣按被邀请用户的在线积分充值计算，以积分发放到账户。邀请注册不等于立即获得充值返佣，也不等于可以提现。

## 容量不足

先在存储用量中区分文件容量与其他限制，再清理不再使用且允许删除的资源，或购买当前站点提供的存储权益。积分充足不代表存储空间充足。
