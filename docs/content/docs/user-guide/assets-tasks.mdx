## 素材库

入口：左侧素材（`/assets`）。素材库用于整理创作资料，任务页用于追踪生成过程，两者用途不同。

1. 按类型、分类、文件夹、标签或搜索词查找素材。
2. 新增文字或上传页面支持的文件；确认文件上传和记录保存均成功。
3. 编辑名称、标签、说明与文件夹，让以后能按用途找到它。
4. 在画布或生成页从素材选择器引用；先预览，避免选错相似文件。
5. 需要迁移时使用导入资产包、导出或导出全部入口；模型文件使用专门的模型上传入口。

Eagle 连接见 [插件指南](./skills-plugins.mdx)。方舟素材需要站点开放及相应授权，不能把普通图片直接视作已认证的人像素材。

## 删除与容量

删除前核对素材是否仍被项目或画布使用。若系统提示存在引用，先定位引用来源再处理。回收站和彻底删除按当前界面及站点保留策略执行；彻底删除前保留需要的备份。

容量不足时，先看存储用量和回收站，再检查不再需要的附件与素材。删除一条记录后容量没有立即变化，并不意味着应该反复删除更多内容。

## 历史任务

入口：左侧历史任务（`/tasks`），需站点开放。可按状态、画布、类型和模型等筛选，切换列表或网格视图。

1. 先清除不必要的筛选，确认登录的是创建任务的账号。
2. 找到任务，查看提示词、关联画布、状态和结果预览。
3. 正在运行的任务先等待；不再需要时使用可用的取消入口。
4. 已失败任务先阅读原因，再决定恢复、重新保存还是重新生成。
5. 完成后核对作品能打开，并返回关联画布确认是否写回。

## 选择正确的恢复操作

| 现象 | 先做什么 |
| --- | --- |
| 页面断线但任务可能还在运行 | 查询原任务或重新获取结果 |
| 已生成但资源保存失败 | 使用重新保存入口 |
| 任务已明确失败 | 修正输入、模型或额度，再重试 |
| 结果存在但画布里没看到 | 打开关联画布、刷新并定位对应节点 |
| 筛选后列表为空 | 清除筛选，核对账号和项目 |

重试生成可能产生新费用，取消也不代表一定退款。账务问题请对照 [积分记录](./wallet.mdx)，提交反馈时附任务编号和发生时间。
