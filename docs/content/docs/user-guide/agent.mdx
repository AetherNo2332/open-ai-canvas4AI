## 什么时候使用 Agent

Agent 适合把目标拆成步骤、读取画布资料和协助操作节点。首页的助手入口与画布助手按实际开放情况显示；需要改动画布时，先确认当前画布正确。

## 发起一轮任务

1. 打开助手面板，选择可用模型。
2. 说明目标、输入、期望产物和约束。例如：「参考这张商品图，先规划三种背景方案，等我确认后再生成」。
3. 上传附件，或用 `@` 选择画布节点；用 `/` 选择已可用的技能。
4. 检查已选引用和技能，发送请求。
5. 根据回复补充资料；出现审批卡片时，核对对象数量、修改范围、生成数量及费用提示，再批准或拒绝。

不要把对话里的“计划完成”当成任务已经落地。查看实际节点、作品和任务记录，确认结果符合要求。

## 审批与批量制作

批准会继续执行相应操作；拒绝后检查本轮状态，再发起明确的新指令。审批结果不确定时先刷新原运行状态，避免重复点击引起混淆。

批量制作按界面提供的试跑、继续、取消等阶段推进。先验证少量样本，再扩大范围。运行中发送消息时，按输入区提供的插队或排队方式选择；排队消息不会立刻取代当前工作。

若界面提供撤销，先核对将撤销的步骤；撤销画布修改不等于撤回供应商调用，也不意味着费用自动退回。

## 记忆与技能的区别

技能描述一种可重复使用的做事方法；记忆保存与你有关、以后仍可能有用的约定。设置中的 Agent 记忆用于查看和编辑记忆，按可用入口检查修订、撤销和待采纳内容。

1. 阅读新记忆或修改建议，核对是否真实、是否仍适用。
2. 修正错误后再保存或采纳；一次性要求不必都保存为长期偏好。
3. 记忆发生不合适变化时，查看修订与撤销入口，确认恢复范围。

## 助手不能继续时

没有模型、执行器离线、等待审批、额度不足是不同问题。先读状态提示并处理对应原因；执行器离线需要管理员处理。页面断线后先返回原对话查看状态，避免重发整套批量任务。
