## 什么时候使用 Agent

Agent 适合把目标拆成步骤、读取画布资料和协助操作节点。首页的助手入口与画布助手按实际开放情况显示；需要改动画布时，先确认当前画布正确。

## 发起一轮任务

1. 打开助手，选择可用模型。起步建议只填写草稿，不会自动发送或修改素材。
2. 说明目标、输入、期望产物和约束。例如：「请先问我想呈现的情绪，再比较两种视觉方向，暂不生成素材」。
3. 在画布 Agent 中上传附件，或用 `@` 选择画布节点；用 `/` 选择已可用的技能。短剧分析只使用当前短剧项目的只读资料。
4. 检查已选引用和技能，发送请求。
5. 根据回复补充资料；出现审批卡片时，核对对象数量、修改范围、生成数量及费用提示，再批准或拒绝。

不要把对话里的“计划完成”当成任务已经落地。查看实际节点、作品和任务记录，确认结果符合要求。

## 审批与批量制作

批准会继续执行相应操作；拒绝后检查本轮状态，再发起明确的新指令。审批结果不确定时先刷新原运行状态，避免重复点击引起混淆。

批量制作按界面提供的试跑、继续、取消等阶段推进。先验证少量样本，再扩大范围。运行中发送消息时，按输入区提供的插队或排队方式选择；排队消息不会立刻取代当前工作。

若界面提供撤销，先核对将撤销的步骤；撤销画布修改不等于撤回供应商调用，也不意味着费用自动退回。

## 共享偏好和会话历史

在「设置 → 偏好」维护回答语言、语气、详略和格式。新一轮画布协作和短剧分析都可以使用这些偏好。保存时遇到版本冲突，先刷新读取另一处保存的设置，再确认修改。

画布和短剧各自保留会话历史。切换项目后，从当前业务的会话列表恢复。归档会话收起历史入口，执行中的轮次可单独取消。旧会话可用于查看历史，若页面提示上下文版本过旧，请新建会话。

技能描述可反复使用的工作方法。业务记忆默认关闭，明确开启的配置会将记忆保存在当前业务对象内。设置中的旧账户记忆和系统提示词可继续查看和维护。

## 助手不能继续时

没有模型、执行器离线、等待审批、额度不足是不同问题。先读状态提示并处理对应原因；执行器离线需要管理员处理。页面断线后先返回原对话查看状态，避免重发整套批量任务。
