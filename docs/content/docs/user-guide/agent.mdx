## 什么时候使用 Agent

Agent 适合把目标拆成步骤、读取业务资料和协助操作。画布、短剧和创作首页共用右侧悬浮面板；页面没有显示入口时，说明这个页面尚未接入，可以用 `⌘/Ctrl+J` 再确认。需要改动画布时，先确认当前画布正确。

## 当前页面与入口

- 画布编辑器接入当前画布，可读取节点、附件和参考图，并按审批结果修改画布。
- 短剧制作台只保留一个全局悬浮入口，不再在剧本正文中嵌入第二套聊天。面板会显示本轮分析剧集，可在发送前切换；历史对话显示上一轮实际剧集，切换选择不会修改旧轮次。
- 创作首页显式接入普通平台对话，只提供文本聊天和运行控制，不读取画布或短剧数据。

不同页面、账号和业务对象使用各自的会话、草稿和待确认请求。未接入页面不显示入口，也不会因缺少画布 ID 或能力加载失败自动变成平台聊天。

## 同一套助手面板

画布、短剧和创作首页使用同一套消息、工具卡、思考折叠、历史、队列、插话、追问、模型、推理和上下文用量界面。业务只提供自己的标题、输入提示、目标对象和审批动作，不会出现三套不同的聊天窗口。

- 模型列表只显示满足当前业务要求的模型；旧会话中的失效模型会提示重新选择或自动回退到兼容模型。
- 默认技能会直接显示；是否允许自选技能由服务端能力决定。没有自选权限时，技能库仍可查看但不能启用。
- 运行中切换执行权限会立即提交给服务端；如果服务端未接受，原权限保持不变，下一次运行再使用新选择。
- 图片生成审批可以调整本次模型、尺寸和质量，批准后按调整后的规格执行并重新校验。

## 发起一轮任务

1. 打开助手，选择可用模型。起步建议只填写草稿，不会自动发送或修改素材。
2. 说明目标、输入、期望产物和约束。例如：「请先问我想呈现的情绪，再比较两种视觉方向，暂不生成素材」。
3. 在画布 Agent 中上传附件，或用 `@` 选择画布节点；用 `/` 选择已可用的技能。短剧分析只使用当前短剧项目的只读资料，并在面板顶部选择本轮剧集与积分上限。
4. 检查已选引用和技能，发送请求。
5. 根据回复补充资料；出现审批卡片时，核对对象数量、修改范围、生成数量及费用提示，再批准或拒绝。

不要把对话里的“计划完成”当成任务已经落地。查看实际节点、作品和任务记录，确认结果符合要求。

## 审批与批量制作

批准会继续执行相应操作；拒绝后检查本轮状态，再发起明确的新指令。审批结果不确定时先刷新原运行状态，避免重复点击引起混淆。

批量制作按界面提供的试跑、继续、取消等阶段推进。先验证少量样本，再扩大范围。运行中发送消息时，按输入区提供的插队或排队方式选择；排队消息不会立刻取代当前工作。

若界面提供撤销，先核对将撤销的步骤；撤销画布修改不等于撤回供应商调用，也不意味着费用自动退回。

## 共享偏好和会话历史

在「设置 → 偏好」维护回答语言、语气、详略和格式。新一轮画布协作和短剧分析都可以使用这些偏好。保存时遇到版本冲突，先刷新读取另一处保存的设置，再确认修改。

画布、短剧和平台各自保留会话历史。切换项目或业务后，从当前入口的会话列表恢复；已受理的运行由服务端继续，返回原页面时再观察。短剧换集续聊沿用同一会话，但每轮请求会显式冻结所选剧集。

旧短剧链接中的 `agentProject` 与 `agentRun` 会在校验作品归属后打开原分析轮次；链接属于其他作品、其他业务或缺少归属时会拒绝恢复。归档会话收起历史入口，执行中的轮次可单独取消。旧会话可用于查看历史，若页面提示上下文版本过旧，请新建会话。

技能描述可反复使用的工作方法。业务记忆默认关闭，明确开启的配置会将记忆保存在当前业务对象内。设置中的旧账户记忆和系统提示词可继续查看和维护。

## 画布预演等待录制

画布 Agent 请求预演后，原画布会打开导演台并等待当前浏览器录制。录制完成前不要切到其他业务继续寻找同一个预演入口；在其他画布、短剧或创作首页看到「画布预演等待录制」时，这里只提供返回原画布的链接，不会在错误页面启动录制。

返回原画布后会恢复待录任务，并定位到对应场景和镜头。刷新原画布也可以继续；多个标签页同时打开时，只由当前可见且取得录制权的标签页处理，避免重复生成视频。录制期间离开页面或把标签页置于后台会中止本次录制，回到原画布后可重新尝试。

如果视频已经上传、但回传结果时网络中断，刷新后应复用同一段已上传视频重试，不应再次录制。等待超过页面显示的截止时间后，原请求会取消；需要预演时请让 Agent 重新发起一次。

## 助手不能继续时

没有模型、执行器离线、等待审批、额度不足是不同问题。先读状态提示并处理对应原因；执行器离线需要管理员处理。页面断线后先返回原对话查看状态，避免重发整套批量任务。
