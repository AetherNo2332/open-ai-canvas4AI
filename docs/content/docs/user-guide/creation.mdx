## 首页创作

入口：左侧「创作」或首页（`/`）。首页支持文本、图片和视频创作，并提供历史对话。

1. 选择模式，再选择适合该任务的模型。
2. 写清主体、用途和限制。文本任务说明期望结构；图片说明画面；视频补充动作和镜头变化。
3. 按模型支持的方式添加附件或引用素材。看到附件不等于该模型一定支持它，以上传和提交校验为准。
4. 调整页面显示的尺寸、比例、质量、数量或视频时长等参数。
5. 核对费用后提交，等待结果。需要修改时基于原对话继续说明具体变化。

不要一次改变全部条件。先用少量输出确认方向，再增加数量，有助于比较效果和控制费用。

## 图片与视频工具

入口：左侧图片工具（`/toolbox/image`）或视频工具（`/toolbox/video`），需站点开放。

1. 选择模型并填写提示词。
2. 需要图生图、图生视频或参考生成时，添加素材并核对用途；只使用当前模型实际提供的参考选项。
3. 在参数区选择画幅与质量，视频还需核对时长等选项。
4. 提交后在结果区域查看状态和预览，使用下载、重试或取消等可用操作。

模型切换后重新核对参数。不同模型可选的尺寸、时长、参考数量和音频能力可能不同，不以其他模型的操作经验替代页面提示。

## 历史与结果

从历史对话返回之前的创作；集中检查生成任务则进入「历史任务」。下载是把作品保存到本机，作品仍需妥善备份；浏览器临时预览地址不适合作为长期交付地址。

| 页面状态 | 建议操作 |
| --- | --- |
| 排队、运行中 | 等待原任务，必要时查看任务中心 |
| 连接中断、重新获取 | 恢复原任务结果，先不要再次生成 |
| 作品已生成、保存失败 | 使用重新保存入口，避免重复生成 |
| 后端已确认失败 | 阅读原因，改正模型、输入或额度问题后重试 |
| 已取消 | 确认任务状态，再决定是否重新创建 |

取消不保证供应商停止计算或立即退费。费用以 [积分记录](./wallet.mdx) 为准。更多排查见 [常见问题](./troubleshooting.mdx)。
