## 空间预演：先确认构图和机位

入口：画布中预演相关节点或操作。预演用于安排人物、道具、场景和摄像机，帮助判断镜头构图。

1. 打开预演工作台，先在摆场模式添加人物或道具。
2. 选择对象，在属性面板调整位置、朝向和尺寸；用对象列表确认选中了谁。
3. 调整摄像机与画幅，在监视器查看最终取景，而不只看自由视角。
4. 需要运动时切换动画模式，打开时间轴，设置相应关键帧。先核对自动关键帧开关是否开启。
5. 播放检查后，使用当前工作台提供的画面输出或录制入口。

预演画面与 AI 生成成片是两种结果。将预演输出用作模型参考后，还需单独提交生成任务。

### 预演检查清单

- 监视器中的画幅、人物比例和遮挡是否正确。
- 拍摄机位与自由观察视角是否区分清楚。
- 动画是否在预期时间发生，关键帧是否写到了正确对象。
- 录制是否实际生成可播放文件；取消录制后不要把中间状态当成导出成功。

## 视频编辑：把素材组织成片

编辑器由插件提供。通过平台展示的编辑器入口打开，若未出现，先检查 [插件中心](./skills-plugins.mdx) 和站点配置。

1. 导入或选择可访问的视频、图片与音频素材。
2. 把素材放入时间线，调整顺序和片段长度，再用预览监视器检查衔接。
3. 选中片段，在属性区调整该类型支持的参数。
4. 需要字幕时使用字幕工具；自动转写依赖站点可用服务，提交后等待任务完成并校对文字。
5. 使用 AI 编辑助手时说明目标，审阅修改范围后确认；完成后重新播放检查。
6. 在导出区核对输出参数，提交并等待可下载的结果。

## 保存与输出问题

预览流畅不代表导出已成功。导出失败时保留工程，记录失败信息，再检查素材是否可读取、容量是否足够、后台任务是否完成。

关闭工作台遇到未保存或保存失败提示时，先处理提示。不能把关闭窗口当成强制保存。
