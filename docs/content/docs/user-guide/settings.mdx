入口：账户菜单中的设置（`/settings`）。通过左侧分类切换；部分分类只在站点或插件开放时出现。

## 每个分类做什么

| 分类 | 主要用途 | 操作后检查 |
| --- | --- | --- |
| 个人资料 | 修改显示信息、头像及页面提供的账户安全信息 | 保存后重新打开确认 |
| 偏好 | 调整个人使用习惯与显示选项 | 返回创作页观察效果 |
| 模型 | 选择各类创作使用的模型与偏好 | 新任务能选到正确模型 |
| 提示词 | 管理个人提示词相关设置 | 新创作是否使用预期内容 |
| Agent 记忆 | 阅读、编辑和处理记忆修订 | 内容准确且适用范围正确 |
| 渠道 | 配置自己使用的模型服务 | 地址、凭据、协议和模型匹配 |
| RunningHub | 配置已启用插件的工作流服务 | 工作流能够接受所需输入 |
| 存储 | 配置个人可用的存储选项 | 连接及资源访问正常 |
| 方舟素材库 | 管理已开放的素材与认证流程 | 状态及授权范围正确 |
| 我的反馈 | 查看已提交问题及处理情况 | 内容和附件完整 |
| 诊断 | 获取排障信息或导出诊断包 | 导出完成，分享前检查内容 |

## 系统模型与个人渠道

系统模型由管理员提供，普通用户选择使用；个人渠道使用你自己配置的服务。站点关闭个人渠道时，相关分类不会显示，请联系管理员提供模型。

配置个人渠道的一般步骤：

1. 在「渠道」新增或编辑服务，选择匹配的协议。
2. 填写服务地址和所需凭据，添加实际可用的模型。
3. 核对模型类型与能力，保存配置；使用页面提供的测试能力检查连接。
4. 回到「模型」或生成页选择它，先提交少量测试任务。

模型名称不是能力保证。图片、视频、文本的协议和参数不能随意互换。配置了渠道但仍没有可选模型时，检查启用状态、模型类型和配置错误。

个人密钥属于敏感信息，反馈截图不要包含完整凭据。更换浏览器或设备后核对个人渠道配置，不能假定所有本地配置已自动迁移。

## 方舟素材与人像认证

入口由管理员开放后出现。按页面提交素材、完成相应认证并等待状态更新；需要手机操作时按提供的认证流程完成并返回。未通过、过期或没有授权的素材不能当作可用参考。

## 保存未成功怎么办

读取失败时先重试读取；保存失败时保留当前输入并检查错误。页面显示保存完成后再退出。涉及模型或存储配置的调整，最好用一项小任务验证，而不直接启动大批量制作。

详细记忆使用见 [Agent 指南](./agent.mdx)，容量和付费见 [积分与存储](./wallet.mdx)。
