## 创建与打开画布

入口：左侧「画布」（`/canvas`），打开已有画布或使用创建入口。画布编辑页位于 `/canvas/画布编号`。

给画布取能描述任务的名称，例如「咖啡杯新品海报」。先放入参考和说明，再开始生成，便于以后恢复创作上下文。

## 节点与参考关系

1. 在工具栏选择「添加节点」，选择当前提供的文字、图片、视频、音频等类型。
2. 填写内容或上传素材，使用节点名称旁的编辑入口命名。
3. 为生成节点选择模型，填写提示词，添加引用或连接参考节点。
4. 核对引用的对象与顺序，再提交生成；连接线表示关系，不代表已经触发收费生成。
5. 完成后检查结果，按节点提供的操作下载、继续编辑或作为下一步参考。

不同节点可用操作不同。例如有些图片操作需要先选中图片并加载完成；模型不支持的参考方式不能靠连接线强行启用。

## 选择、排列和查看

- 用抓手移动视野，用框选选中多个节点；缩放和适配视野帮助定位作品。
- 多选后可对齐、排列；等距分布通常需要至少三个对象。
- 使用撤销、重做处理编辑失误。删除节点、清空画布前先核对对象范围。
- 工具栏设置可调整常用入口；画布外观用于调整展示，不改变模型生成内容。
- 工作区面板提供节点、资产、任务、历史等入口，适合查找大画布中的对象。

## 图片工具与姿势参考

选中图片后查看它提供的编辑、风格、预设和后续生成操作。拆分或导出图片与重新调用模型是不同动作，提交前确认是否创建新任务。

需要局部改图、去背景、多视图、提取视频声音或生成音频时，阅读 [图片、视频与音频工具](./media-tools.mdx)。

使用「姿势库」时，浏览分类、选择视角，将姿势图插入画布并作为图片生成参考。空列表可能是管理员尚未同步图库；用户端不负责导入站点图库。

## 版本、保存与分享

作品存在多个媒体版本时，在版本入口比较并选择使用的结果；换选用模型不会自动改变旧作品的生成来源。历史浏览状态与正常编辑状态不同，先退出历史浏览再修改。

关注保存状态。出现仅本地保存或同步失败提示时，先恢复连接并确认服务端保存，再关闭页面或换设备。

分享时使用画布提供的分享入口，核对分享内容后复制链接。接收者看到分享视图；发送前去除不希望公开的文字和素材。分享不能代替可编辑工程的备份。

需要助手操作看 [Agent](./agent.mdx)，需要摆场或剪辑看 [预演与视频编辑](./previs-editor.mdx)。
