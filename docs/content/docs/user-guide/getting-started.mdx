## 开始前需要什么

- 一个可用账号。登录页展示哪些登录、注册和找回方式，由站点配置决定。
- 一个可选模型。管理员可提供系统模型；开放个人渠道的站点也允许配置自己的服务。
- 收费模型需要足够的可用积分；上传参考素材还需要可用存储空间。

## 登录与注册

1. 打开平台，点击登录，按页面要求填写账号信息。
2. 需要注册时使用页面提供的注册入口。没有入口时，联系管理员开通账号。
3. 忘记密码时使用页面提供的找回方式。收不到邮件时检查垃圾邮件、地址和错误提示，再联系管理员。
4. 登录后确认账户菜单里的账号正确，再上传私人素材。

## 认识工作区

左侧菜单用于进入创作、画布、短剧、电商、工具、技能、素材和历史任务；实际项目受功能开关影响。顶部提供文档、语言、反馈、积分、公告、主题和账户入口，部分入口只在登录或功能启用时出现。

窄屏上使用菜单按钮展开侧栏。个人设置和管理后台在账户菜单中，管理员才有后台权限。

## 完成第一张图片

1. 回到首页，选择图片创作模式。
2. 选择可用图片模型，先使用默认尺寸和少量输出。
3. 输入描述，例如：「木桌上的白色陶瓷杯，窗边自然光，干净背景，商品摄影」。
4. 需要参考外观时上传相关图片，确认上传成功。
5. 核对模型、数量和显示的费用，提交生成。
6. 等待完成后预览作品，再使用结果区域提供的下载或后续创作操作。

看到可打开的结果才算完成；提交成功、排队或进度动画都不等于生成成功。

## 下一步与常见阻碍

模型列表为空时看 [个人设置](./settings.mdx)；找不到作品时看 [素材与任务](./assets-tasks.mdx)。任务仍在运行时不要连续重复提交，先查看原任务状态。

想组织多张作品可继续 [画布与节点](./canvas.mdx)，只想调整生成参数可继续 [首页创作](./creation.mdx)。
