这套指南面向使用影策完成创作的用户。无需先配置服务器；如果平台没有提供模型或未开放功能，请联系站点管理员。

## 推荐阅读顺序

1. [快速开始](./getting-started.mdx)：登录、认识工作区，完成第一张图片。
2. [首页创作与生成工具](./creation.mdx)：熟悉模型、参考素材和任务状态。
3. [素材与任务](./assets-tasks.mdx)：找到结果，整理可重复使用的素材。
4. 根据目标进入 [画布](./canvas.mdx)、[短剧](./short-drama.mdx) 或 [电商创作](./ecommerce.mdx)。

## 全部功能入口

| 功能 | 用途 | 指南 |
| --- | --- | --- |
| 首页、图片工具、视频工具 | 对话、快速生成和参数调整 | [创作](./creation.mdx) |
| 画布 | 节点、参考关系、版本与分享 | [画布](./canvas.mdx) |
| 图片、视频与音频工具 | 局部编辑、多视图、提取、增强、音频生成 | [媒体工具](./media-tools.mdx) |
| Agent | 规划、操作画布、批量制作和记忆 | [助手](./agent.mdx) |
| 预演、编辑器 | 空间构图、动画、剪辑和字幕 | [预演与编辑](./previs-editor.mdx) |
| 短剧创作 | 导入故事、分集、制作成片 | [短剧](./short-drama.mdx) |
| 电商 | 商品主图、详情图、SKU 与营销素材 | [电商](./ecommerce.mdx) |
| 素材、历史任务 | 上传、分类、导入导出、进度和恢复 | [素材与任务](./assets-tasks.mdx) |

| 积分、签到、推广 | 购买、兑换、记录与邀请奖励 | [积分与推广](./wallet.mdx) |
