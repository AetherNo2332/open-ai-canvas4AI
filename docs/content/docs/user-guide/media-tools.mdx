入口：画布中选中已经加载完成的图片、视频或音频节点，打开节点工具栏。工具会随素材类型、模型能力、插件和站点配置变化；灰色入口先查看提示。

## 图片工具如何选择

先确定需要修改什么，再选择对应工具。保留原图方便比较，涉及生成的操作提交前核对模型、参数和费用。

| 目标 | 对应工具或操作 | 操作重点 |
| --- | --- | --- |
| 换素材、调整显示大小 | 替换、尺寸调整、查看原图 | 核对是否替换了生成参考，不把显示缩放当成分辨率提升 |
| 去掉边缘或拆出格子 | 裁剪、拆分 | 先确认裁剪范围或格子边界，再应用 |
| 用图说明修改位置 | 标注、标注编辑、区域编辑 | 明确选区和修改要求，检查未选区域是否保留 |
| 改图中文字 | 文字编辑 | 提供准确文案，生成后放大校对字体与拼写 |
| 去背景、分层 | 去背景、图层分解 | 检查边缘、透明区域和分层结果 |
| 调整人物表现 | 表情、人物质感 | 核对身份、五官和皮肤细节，避免意外改脸 |
| 提高清晰度 | 放大、超分辨率 | 对比细节，不只比较输出尺寸 |
| 换构图或光线 | 视角、光照、全景等 | 描述目标变化，检查主体结构是否保留 |
| 复用提示词 | 复制提示词、反推提示词 | 反推内容只是对画面的描述，不保证复现原图 |
| 做镜头或多视图参考 | 多机位九宫格、故事四格、分镜、人物或商品三视图等 | 核对每格主体一致性及排列，再用于后续创作 |
| 从图片进入空间构图 | 预演相关入口 | 依赖助手和预演能力，结果要在预演台检查 |

### 一次局部修改

1. 选中目标图片，打开区域编辑或对应编辑工具。
2. 标出需要修改的位置，写清替换内容和保留条件。
3. 选择可用模型，核对参考图和生成参数。
4. 提交后比较新旧结果，重点看未修改区域和主体一致性。
5. 选择满意结果继续创作，原图仍作为对照保存。

## 视频处理

视频节点提供的操作包括提取素材、分段处理和画质增强等，实际以节点工具栏为准。

- **提取画面**：选择需要的画面作为图片参考，检查提取位置。
- **提取音频**：把视频声音提取为 MP3 音频节点，原视频声音仍保留。
- **分段剪取**：核对起止范围和片段顺序，生成后逐段预览。
- **画质增强**：提升分辨率与细节，结果另存为新视频节点；检查内容与时长是否符合预期。
- **下载 / 保存到素材库**：分别用于本机交付和平台内复用。

不要把提取片段、AI 增强和完整编辑器导出混为同一个操作。需要多轨剪辑、声音与字幕时阅读 [视频编辑](./previs-editor.mdx)。

## 音频生成与参考

1. 添加音频节点，选择可用音频模型。
2. 填写要表达的内容或音频描述，按模型要求添加参考。
3. 在音频设置中选择或填写已开通的音色，设置格式和可用的语速选项。
4. 提交后试听，检查内容、发音、停顿和格式，再下载或加入素材库。

部分模型允许提示词生成、音频参考或图片参考，限制不同。以当前参数面板为准；例如面板明确禁止图片与音频混用时，应只保留一种参考。音色 ID 必须属于当前服务已开通的音色，任意填写名称不会自动创建音色。

已有音频可上传或替换到音频节点。使用参考声音前确认有权使用；试听通过后再投入批量制作。

## 工具失败

检查素材加载状态、模型支持、参考限制和错误信息。处理过程中出现保存失败时优先恢复已完成结果，详见 [任务恢复](./assets-tasks.mdx)。
