## 电商 Agent 配置

入口：电商 Agent → 电商 Agent 配置（`/admin/ecommerce/agent`）。

1. 准备可用模型，确认文字策划、图片生成和可选视频能力。
2. 在电商配置中选择页面要求的模型和选项，保存。
3. 使用普通账号上传一份测试商品资料，完成事实确认、方案审阅和少量生成。
4. 检查商品外观、输出数量、画幅和费用，确认不会使用错误的模型能力。

模型未开放或能力不匹配时，先修复模型配置，再开启用户入口。详情见 [模型与渠道](./models-channels.mdx)。

## 知识与技能

入口：知识与技能（`/admin/ecommerce/library`），包含知识、Skills 和品类相关页面。

| 内容 | 应维护什么 | 验证方式 |
| --- | --- | --- |
| 知识 | 有来源、适用范围明确的视觉与商品规则 | 检查检索和策划是否采用正确资料 |
| Skills | 适合具体创作任务的处理方法 | 普通账号执行相应场景 |
| 品类 | 商品分类及其关联信息 | 选择品类后检查上下文与方案 |

导入或更新后核对审核、启用与版本状态。社区资料不应未经核对就作为权威规则；已经过时的平台要求应及时更新或停用。

## 一次完整验收

选择代表性商品 → 填写真实规格和禁改细节 → 确认商品事实 → 查看方案 → 生成少量图片 → 检查文字和产品保真 → 查看任务及费用。

尺寸、材料、包装、价格和促销信息应来自用户提供的真实资料。公共知识可以帮助策划，不能替用户编造商品事实。

用户操作见 [电商创作指南](../user-guide/ecommerce.mdx)。
