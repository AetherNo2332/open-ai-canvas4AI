这些配置影响用户可用的创作资源。先在后台准备并验证，再开放给普通用户。

## 工作台工具与提示词模板

入口：创作与扩展 → 工作台工具（`/admin/workbench-tools`）、提示词模板（`/admin/prompt-templates`）。

1. 新增或编辑条目，填写名称、类型、内容和适用范围。
2. 核对展示说明是否让用户理解用途，不把后台参数当成使用说明。
3. 保存并按页面设置启用状态。
4. 用普通账号在对应创作或节点入口选择条目，检查输入与实际结果。

不同节点支持的工具不同，不保证模板在所有编辑器中出现。停用前检查正在使用的工作流。

## 姿势库

入口：姿势库（`/admin/pose-library`）。先导入元数据，核对体系和分类，再同步图片；失败条目重试，完成后从用户端选择姿势验证。

仓库镜像不附带姿势图片。管理员负责确认素材使用条件，不能把元数据导入成功当成图片已可用。详细导入、同步和来源管理见 [姿势库专题](../canvas/pose-library.mdx)。

## 绘图工具

入口：绘图工具（`/admin/settings/drawing-engine`）。按页面选择和配置绘图能力，保存后进入真实画布验证创建、编辑和保存。外部资源或授权缺失时先处理相应错误。

## Agent（beta）

入口：Agent（beta）（`/admin/settings/agent`）。配置调度槽、执行器驻留会话、用户与画布会话上限，以及页面提供的默认技能、联网和子代理能力。

1. 先确认执行器在线、模型和工具依赖可用。
2. 从保守并发开始，根据队列、执行耗时与服务器资源调整。
3. 配置默认技能和外部能力后，测试一轮普通对话、一轮审批和一次画布写入。
4. 缩容后观察已有会话排空；不要把会话数、调度槽和生成任务并发混为同一参数。

用户看到执行器离线时，单独增加并发不能解决离线问题。问题排查见 [运营指南](./operations.mdx)。

## 插件管理

入口：插件管理（`/admin/plugins`）。查看插件详情、版本、权限和依赖，按安装包或页面支持的来源安装。补齐配置后启用，再测试它贡献的实际功能。

更新、停用或卸载可能影响依赖该插件的模型协议、支付或编辑器功能。先列出依赖入口，再操作；不要把安装完成等同于外部服务已经打通。

## 技能管理与技能分类

入口：技能管理（`/admin/skills`）和技能分类（`/admin/skill-curation`）。

1. 准备或导入公共技能，检查名称、说明和内容。
2. 在技能分类维护分类、推荐和页面提供的分发设置。
3. 用普通用户在发现页搜索、加入并调用技能。
4. 技能改版后抽查实际使用，避免说明仍引用已删除的工具。

技能工作台编辑的是方法说明；它不能替代后端权限，也不会自动提供模型密钥。分类管理细节见 [技能策展专题](../backend/skill-curation.mdx)。

## Agent 记忆

入口：用户与运营 → Agent 记忆（`/admin/agent-lessons`）。先选对用户或目标范围，再查看、编辑或处理页面提供的记忆修订。保存后核对记录；不要把某个用户的一次性需求写成所有用户的公共约定。
