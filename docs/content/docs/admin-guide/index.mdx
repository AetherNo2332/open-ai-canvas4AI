## 管理操作的基本顺序

1. 读取当前配置，确认正在管理的站点和对象。
2. 修改最小必要范围，检查输入和影响用户。
3. 保存并确认服务端返回成功；结果不确定时先重新读取。
4. 使用普通测试账号验证实际效果，再扩大开放范围。

后台保存成功只证明配置被接受，不能代替上游模型、支付回调、邮件或存储的真实联通验证。
