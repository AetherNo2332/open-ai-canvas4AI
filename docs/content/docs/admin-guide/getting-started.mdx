## 配置前

确认自己有管理员权限、当前站点已完成基本部署、需要接入的模型与存储资料齐全。首次部署的具体步骤见 [部署指南](./deployment.mdx)。

## 推荐顺序

1. **站点及外观**：设置站点名称、标识和必要展示信息。
2. **登录与注册、邮件服务**：决定开放的注册与验证方式，实际测试验证码或找回邮件。
3. **渠道与模型**：先配置一个可用模型，测试真实小任务，再配置更多模型。
4. **前台模型**：若启用统一前台模型，完成模型映射、能力与价格，再开放给用户。
5. **存储服务、资源与策略**：确认上传、读取、容量与任务限制适合当前机器和上游。
6. **积分与支付**：需要收费时配置商品、支付方式和账务策略，先验证小额完整流程。
7. **功能开放**：只开放已经配置好依赖的入口。
8. 用普通测试账号完成登录、选模型、生成、打开作品、下载和查看记录。

## 功能开放

入口：系统设置 → 功能开放（`/admin/settings/features`）。图片工具、视频工具、任务中心、插件中心、短剧、个人渠道等功能会影响用户可见入口；具体开关以页面显示为准。

开启入口不等于模型、执行器或支付服务已经可用。关闭入口也不等于删除已有作品。调整前先确认是否有用户正在使用，保存后用普通账号检查菜单和访问提示。

## 上线前最小验收

| 项目 | 通过标准 |
| --- | --- |
| 登录与权限 | 普通账号能登录，不能进入后台 |
| 模型 | 用户能选择预期模型并完成小任务 |
| 素材 | 上传成功，重新打开仍能读取 |
| 计费 | 报价、订单和积分记录相互对应 |
| Agent（若开放） | 助手在线，审批及画布结果可验证 |
| 文档 | 顶栏入口打开同域文档，正文与搜索可用 |

先处理阻断基本使用的问题，再逐项开放高级功能。对应说明见 [模型](./models-channels.mdx)、[系统设置](./system-settings.mdx) 和 [运营排查](./operations.mdx)。
