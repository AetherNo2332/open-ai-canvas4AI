## 站点及外观

入口：系统设置 → 站点及外观（`/admin/settings/appearance`）。修改品牌名称、Logo、站点展示及页面提供的皮肤、登录页和助手外观配置。

保存后检查首页、登录页、明暗主题和窄屏，确认文字可读、图片可加载。助手名称和外观不会改变它拥有的业务权限。更深入的助手素材说明见 [画布 Agent 外观](../backend/canvas-agent-appearance.mdx)。

## 登录与注册、邮件服务

入口：登录与注册（`/admin/settings/access`）、邮件服务（`/admin/settings/email`）。

1. 选择站点允许的注册和验证方式。
2. 配置邮件服务所需地址、账号、凭据与发信信息。
3. 保存并发送测试邮件，再从普通用户端验证注册或找回流程。
4. 收不到邮件时结合邮件记录检查发送失败、收件地址和投递情况。

关闭注册影响新用户进入，不应当作冻结已有账号的替代方式。修改验证策略前，先确认已有用户仍有可用登录与找回路径。

## 存储服务

入口：存储服务（`/admin/settings/storage`）。根据页面支持的存储类型填写地址、桶、区域和访问凭据等必要信息。

1. 读取当前配置，确认现有资源使用的位置。
2. 填写新配置并使用连接测试。
3. 上传小文件，检查用户预览、下载以及模型读取参考素材的路径。
4. 再检查一份旧资源，确认历史作品仍能访问。

连接测试成功不等于历史文件已经迁移。切换存储前先明确旧资源如何继续访问和备份，迁移应由运维按实际环境执行。

## 资源与策略

入口：资源与策略（`/admin/settings/runtime-policy`）。

| 策略组 | 调整内容 | 调整前考虑 |
| --- | --- | --- |
| 资源限制 | 单文件、每日上传、账号容量、素材/画布/任务数量 | 当前用户占用和购买权益 |
| 回收站 | 自动清理保留期 | 需要恢复的资源是否已备份 |
| 存储访问 | 传输超时、访问地址有效期等 | 网络速度与模型读取时间 |
| 任务执行 | Worker 并发、渠道并发、账号活动任务、超时 | 上游限额与服务器负载 |

先小范围调整并观察，不用无限增大超时或并发掩盖持续失败。普通生成任务 Worker 与 Agent 会话调度是不同设置。

## 方舟素材库

入口：方舟素材库（`/admin/settings/ark-private-assets`）。配置并管理素材分组、用户授权与页面提供的审核事项。开放前用测试账号检查上传、认证、状态刷新和使用权限。

授权范围应与实际使用者一致；用户端能看到分类不代表所有素材都已完成认证。

## 第三方参数配置

入口：第三方参数配置（`/admin/settings/third-party`）。集中维护页面支持的外部服务参数，包括相应集成的地址和凭据。每次只调整一项连接，保存后测试对应真实功能。

服务有有效凭据仍可能因余额、权限或网络失败。使用错误提示和请求记录定位，不把凭据复制到公告或公开文档。

## 模型响应拦截

入口：模型响应拦截（`/admin/settings/response-interception`）。配置启用状态及有顺序的匹配、替换规则。

1. 新建最小范围规则，核对匹配文本和替换结果。
2. 保存后用明确样本检查命中和未命中情况。
3. 多规则时核对顺序，避免过宽规则覆盖正常内容。
4. 保存结果不确定时重新读取后核对，不连续覆盖提交。

此设置处理模型返回内容，不应被理解为完整的用户输入审核或所有生成媒体审核。站点需要其他审核能力时，应另行明确范围。

系统性能与问题处理见 [运营指南](./operations.mdx)，系统更新见 [部署指南](./deployment.mdx)。
