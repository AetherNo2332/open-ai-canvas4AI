# 后端数据库

## Agent 持久消息队列

数据库当前迁移版本为67。迁移65新增 `agent_queued_messages`、`agent_conversation_queues` 和 `agent_ui_settings`，迁移66新增 `canvas_media_versions`，迁移67为 `cloud_agent_executions` 增加可空的 `archived_at`。既有运行、会话正文及记忆数据保留。迁移清单与 `database.Models()` 共用同一模型定义。

删除 Agent 对话采用持久归档：当前账号的会话轮次写入 `archived_at`，目录按同一会话任一轮的归档标记返回 `archived`，其他设备据此移除缓存入口。运行检查点不能覆盖归档字段；后续已排队轮次不会让对话重新出现。归档不取消任务、不删除运行和费用凭据，`conversation_archived` 仅为目录查询投影，不建数据库列。

消息表以 ID 为主键，`user_id + idempotency_key` 唯一，按账号、会话、状态和 sequence 查待发项。记录原提交指纹、当前 RequestJSON/Prompt、投递方式、revision、问题关联、状态、绑定运行以及派发 token/parent/租约/重试时间。编辑只改当前正文，不改原 POST 指纹；派发或移除后清理请求正文并保留收条，未知重试不会新建或复活消息。插队优先级持久保存，显式恢复请求另有 `dispatch_requested` 标志；停止、暂停或新的异常暂停撤销此前未完成的恢复意图，之后的新提交可重新发起恢复。

队列控制以账号、会话为复合主键，保存 revision、顺序号、暂停原因、未回答 questionId/轮次及已处理终态。提问事件与异常终态在既有检查点事务中同步控制状态，旧提问从完整事件恢复，不依赖尾部窗口。账号发送设置只有默认方式、revision 和更新时间，不复用历史个人偏好或系统提示词表。

入队不建 holding task 或冻结费用。派发先领取一分钟可恢复租约、在事务外准备现有准入，再于账号持久锁内复核 token、租约有效期、最新父轮、暂停与问题状态，同时提交运行、holding task、额度预留、消息绑定和队列 revision。停止会作废准备中的 token；已先提交的续轮成为停止目标。前台即时派发与周期补扫使用相同的持久候选顺序，不由浏览器或 Agent SDK 推进。

当前消息正文、指纹和公开错误字节计入账号 TaskBytes；实际建轮时同一事务替换待发正文与任务数据占用。普通待发数量单独由后台限额控制，降低限额不删除既有消息。临时失败按原身份自动重试，自动尝试累计六次后暂停；明确准入错误直接保留消息并暂停，没有自动过期或静默丢弃。

## 画布写入、编辑租约与实体代次

迁移63创建 `canvas_node_edit_leases`，以画布与节点为主键，保存账号、浏览器会话、私有证明和到期时间；30秒租约在账号、画布的同一持久锁内获取和验证。新时间统一UTC，SQLite读取已有带时区偏移的临时记录时按真实时刻过滤。占用状态和实时事件不返回证明，证明也不进入画布文档、命令回执或历史。

迁移64为 `canvas_entity_versions` 增加非空、默认0的 `generation`。旧实体保持0；初次创建以及删除后重建使用本次提交版本作为新代次，存活实体的普通更新保持原代次。命令、Host、旧PUT、恢复和节点撤销重做共用版本维护边界；同一批次删除并重建相同ID，即使最终JSON相同也换代。旧回执不补写新字段，旧客户端缺少代次证明时继续严格版本校验。

所有持久画布写入按账号、画布顺序协调，在同一事务更新revision、epoch、实体版本、事件及资源保护；账号配额也在持久锁内计算。旧PUT和Agent写入会更新命令投影，客户端可以沿同一事件流补读。整画布命令删除保留恢复所需的内部记录；正常库列表、计数和占用入口按有效epoch判断存活。整画布删除后的恢复使用 `RestoreVersion`，不承诺普通Undo可以撤销该终态。

实时presence没有新增数据表。服务端从基础数据库连接批量观察有在线设备的画布，只发布已提交元组的失效通知；Redis中的设备号、光标和拖动状态均为临时数据。项目素材关联复用现有 `Project.Revision` 做条件更新，没有为重试新增服务端队列表。

`CanvasActorHistory` 继续承担命令撤销，既有 `canvas_snapshots` 承担用户可浏览的云端版本。命令保存与旧保存共用五分钟间隔、20条上限及快照资源保留策略；历史恢复强制备份当前状态，并保留当前行的项目归属和创建时间。两种历史与文档在同一事务内维护，不能用不可见的撤销记录代替版本列表。

## Agent 准入与 Worker 身份

迁移60为 `agent_scheduler_settings` 增加 `max_resident_per_user` 并为已有行回填默认32；`agent_user_admissions` 按用户保存上次准入序列。既有 `agent_admission_counters` 在准入事务内串行化策略更新与领取；统计跨执行器有效租约，先按用户、再按该用户的画布公平选择。queued、running、waiting_approval 中仍有有效租约的运行计入驻留；过期、释放和终态归还名额。`user_capacity` 与 `canvas_capacity` 等待保留，不按 Worker 未领取超时清理。

迁移62为既有 `agent_runtime_instances` 增加 `readiness` 和 `readiness_reason`，旧心跳回填为 `starting`，必须收到新的 Worker 就绪报告后才可准入。容量判断只使用新鲜、ready、非 draining 心跳；配置版本0是有效默认配置，不作为未就绪标志。

迁移61创建 `agent_workers`：身份 ID、凭据 SHA-256 摘要、可选用户作用域、撤销时间及创建/更新时间。凭据只在管理员创建响应中返回一次，列表和 JSON 不含摘要。环境引导只插入新身份，重启不会覆盖凭据、作用域或撤销状态。运行授权为短期签名数据，不另建持久化 token 表；每次访问继续查询当前 run/session 的用户、owner、epoch、有效租约和非终态，数据库始终是失效判断依据。

## 用户自定义 Agent 系统提示词

复用 `agent_profiles` 表，以 `scope=system_prompt`、当前 `user_id`、空 `project_id`/`canvas_id` 保存账户级提示词；不新增表或列。`content` 为正文，`revision` 沿用现有比较并交换更新，用于阻止旧页面覆盖新内容。该 scope 由 `/api/agent/settings` 管理，运行创建时将正文写入已冻结的系统上下文。原有 user/project/canvas 偏好层已停用，旧行保留，不再读取或注入新运行。

画布规则继续保存于 `agent_workspaces`，按当前账号及 `canvas_id` 读取，并用 `revision` 并发校验。`agent_workspace_skills` 历史表与记录保留，但配置接口、读取和运行覆盖层已停用；新运行不查询该表，旧会话基线中的 workspace 来源也不会装配；已创建运行里冻结的 Workspace 公共技能保留只读文件访问，不恢复配置或新运行覆盖。未新增或删除数据库表、列，无需数据迁移。

## 已停用的工具快照表

工具快照检测机制已移除，相关模型和运行读写路径不再注册。迁移 59 保留原有版本与校验记录，但不再创建工具快照相关表；既有历史表与运行记录中的旧列不自动删除。新工具总数直接从后端目录计算，不需要持久化快照。

## 分镜声明式引用（未新增表或列）

分镜编辑的可选 `operationId` 复用 `CanvasCommandReceipt`（`canvas_command_receipts`），使用 `client_id=agent:storyboard` 与当前用户、画布、epoch 隔离。`CanonicalJSON` 保存去除版本前置条件后的完整操作参数，`ReceiptJSON` 保留目标行/字段、追加行身份及原提交版本，和画布修改同一事务提交；相同标识但参数不同不覆盖旧记录。没有新增进度表、列或迁移。表级版本复用 `CanvasDocumentEpoch` 和 `CanvasEntityVersion.Generation`，防止同 ID 节点删除重建后接受旧读数。

分镜声明式引用没有新增数据表或数据库列，也没有新的迁移版本：权威引用与产物归属保存在画布文档 JSON（`referenceFieldsVersion`、表级 `referenceNodeIds`、行级 `assetBindings`、生成输入的 `generationSpec.referenceBindings` 与 `inputBindings`、行的 `imageNodeId` / `videoNodeId`），派生连线继续放在文档的 `connections`；任务侧复用既有任务输入、`ConsumerJSON`、事件与回执记录以及 `CanvasTaskBinding`。`migrate_references` 只改写文档并产生常规版本、历史与事件，读取投影里的 `referenceMigration` 预览不写库。
