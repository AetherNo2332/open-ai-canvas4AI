# 后端数据库

## 用户自定义 Agent 系统提示词

复用 `agent_profiles` 表，以 `scope=system_prompt`、当前 `user_id`、空 `project_id`/`canvas_id` 保存账户级提示词；不新增表或列。`content` 为正文，`revision` 沿用现有比较并交换更新，用于阻止旧页面覆盖新内容。该 scope 由 `/api/agent/settings` 独立管理，不计入原有 user/project/canvas 偏好层，也不通过 `agent_profile_read` 按需读取。运行创建时将正文写入已冻结的系统上下文。

## 已停用的工具快照表

工具快照检测机制已移除，相关模型和运行读写路径不再注册。迁移 59 保留原有版本与校验记录，但不再创建工具快照相关表；既有历史表与运行记录中的旧列不自动删除。新工具总数直接从后端目录计算，不需要持久化快照。

## 分镜声明式引用（未新增表或列）

分镜声明式引用没有新增数据表或数据库列，也没有新的迁移版本：权威引用与产物归属保存在画布文档 JSON（`referenceFieldsVersion`、表级 `referenceNodeIds`、行级 `assetBindings`、生成输入的 `generationSpec.referenceBindings` 与 `inputBindings`、行的 `imageNodeId` / `videoNodeId`），派生连线继续放在文档的 `connections`；任务侧复用既有任务输入、`ConsumerJSON`、事件与回执记录以及 `CanvasTaskBinding`。`migrate_references` 只改写文档并产生常规版本、历史与事件，读取投影里的 `referenceMigration` 预览不写库。
