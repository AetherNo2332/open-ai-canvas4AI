# 工具快照管理实施计划

> 使用 subagent-driven-development 执行，统一审查后提交；用户已要求完成并提交。

**Goal:** 提前发现后端、worker 与任务冻结工具定义不一致，在运行总览展示告警并支持查看、比较、重新检测、诊断导出和 worker 排空。

**Architecture:** 后端生成权威全集，worker 注册实际内存制品，复用容量心跳。快照不可变；领取时按任务子集比较，严格保留原参数校验规则。当前健康独立于统计日期筛选。

**Tech Stack:** Go/GORM、Pi TypeScript worker、React/Ant Design。

**Spec:** ../specs/2026-10-18-tool-snapshot-management.md。

## 约束和审查重点
- 不修改运行环境，不自动重跑任务，不允许编辑或绕过 schema。
- 缺失/损坏/未上报不能显示为健康；权限工具子集和 JSON 键序变化不能误报。
- 心跳不反复发送全量正文；旧 worker 迁移显示 unknown；严格门禁可配置。
- 现有 optional canvas_inspect_image 兼容规则需要一致保留。
- 排空、注册身份、任务匹配和租约必须防止并发覆盖；多实例不能互相覆盖制品。
