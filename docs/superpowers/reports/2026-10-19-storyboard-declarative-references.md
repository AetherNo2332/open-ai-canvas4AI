## 实现状态

引用字段是权威输入，画布服务派生托管连接。分镜表和行可以声明共享素材、行素材及图像/视频产物归属；普通节点使用 `generationSpec.referenceBindings` 或 `inputBindings`。Agent 合同已移除直接连接操作，提供字段编辑和 `set_references`、`bind_output`、`unbind_output` 语义动作。

已有实现包含原子提交、撤销重做、复制身份隔离、持久任务占用检查、冻结生成输入、迟到结果保护，以及历史画布的一次规范化预览和冲突选择。前端采用真实画布组件及迁移面板，沿用站点皮肤和自托管字体。

本轮提交 `7cf1b695` 补齐普通 Agent `generate_media` 的迁移门禁：审批准备与事务内写入共用校验，历史文档返回 `reference_migration_required`；删除旧的直接建线分支。正常媒体测试夹具改用 v1 文档，历史画布用例显式使用无标记文档，避免以过期夹具为理由保留旧写入路径。

同时保留并核实上一轮未提交的两个修正：共享复制夹具遇到空节点 ID 立即失败；工具说明的 CRLF 预算余量修正为 126 字节（20354 / 20480）。

全量验收另发现一个独立的标注图生成夹具仍无 v1 标记，已由提交 `874cc926` 补齐并复验通过；没有新增产品兼容分支。

Windows 当前 `CGO_ENABLED=1`，但 GCC 的 `collect2` 缺失 DLL，不能用“已安装 GCC”推断测试可运行。本轮数据库回归使用已缓存的 Linux Go 1.25 镜像：禁网，完整仓库和模块缓存只读挂载，独立临时测试容器，不连接业务数据。此前手册只挂载 backend，无法读取跨目录的 web/agent 共享夹具，不能复用于完整验收。容器磁盘临时库 I/O 很慢；app 全量改用 `/tmp` 的 3GiB tmpfs，同一迁移回归从 12.39s 降到 0.60s。tmpfs 需显式 `rw,exec` 才能运行 Go 测试二进制，最初缺少 exec 的启动失败不属于产品断言失败。

web 最初有三个导演台依赖错误。工作树在忽略目录下复用已安装且版本一致的 `three@0.185.1` 后，全量通过，未下载或修改锁文件。格式化后的首次并行测试中，一个格式门禁夹具用例耗时 5.719s，超过默认 5s 上限；构建和 lint 结束后，以 15s 上限重跑全部用例通过，未改测试断言或用例代码。

app 全量中的一个标注图夹具失败已修正。五个 DNS 相关失败分别来自 provider SKU 解析、七牛配置、OSS 访问签名及两项源站交付；在同样禁网的容器中，为测试域名配置受控公共地址 hosts 后通过，仅验证本地准入和签名逻辑，没有请求真实模型或云存储，也不证明真实 DNS 服务可用。仅修改夹具后没有再重复 780s 整包长跑；原全量结果与后续专项结果分开记录。

剩余 `TestValidateAppearanceSkinThemesEnforcesSwissConstraints/rounded-components` 失败属于基线已有冲突：测试将 8px 圆角视为违规，而基线校验允许 0–32px。已核对该分支没有改动任何 appearance 文件，未为引用功能更改外观产品行为或放宽校验。该失败另记入待办，完整 CI 仍不能称为全绿。
