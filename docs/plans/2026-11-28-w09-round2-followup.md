## R2-8 / Canary C-3：失败后无法重试

源码 `openCanvas` 已有 onError，与报告“未处理错误”的描述不同；问题发生在错误回调之前/周围：

1. React Query mutation 默认 networkMode=online，在 offline 时进入暂停，mutationFn 不执行，因而不进入 onError，恢复网络可能隐式继续旧的导航操作。
2. Ensure 请求没有 timeout，网络半断开可无限等待。
3. onError 表达式返回 Ant Design message 的 thenable，React Query 会等待回调完成，按钮状态可能继续 pending。

修复只在进入画布这一操作设置 networkMode=always、retry=false；Ensure API 请求设置 15 秒超时；错误提示不作为回调返回值。后端创建幂等与导航成功条件保持原样，业务逻辑仍在服务端。超时不等于服务端未创建，用户再次进入由 Ensure 复用原画布。

新增独立子进程 DOM 回归，渲染真实详情组件、React Query、Ant Design、路由与 API 客户端，只隔离不相关面板并控制 Axios 适配器。修复前观察到 offline 请求数为 0、timeout 为 0；修复后错误可见、按钮恢复、联网不自动再次提交、手动重试导航成功。有限 timeout 通过实际 API 请求配置验证，真实浏览器超时/离线仍需 VM 验收。
