# 画布与后端上游缺口修复设计

## 目标
在保留我方命令、引用、任务、历史、多 Agent 会话及站点皮肤的前提下，修复已核实的一致性缺口，补齐跨设备 Agent 对话恢复、项目资产关联恢复、节点租约与实时协作状态，以及安全和可缓存的 OSS 交付。

## 固定基线
我方 6c29d06625455ebd6e0d2e9a08c55042ca570f85；上游 cd694236f82e2851393cadc0150ebbde375cdc81。Agent 跨设备参考018acdfcab6cd400f7e9078a4709fb46b98639c0；资产关联恢复参考cd694236。按行为适配，不整包覆盖。

## 已确认需求
1. 所有画布文档写入必须更新同一revision、实体版本和可恢复事件；旧 PUT、Agent、任务回填、恢复/删除不能绕开命令会话的基线。保留引用生命周期和资源历史保护。
2. 创建、增长在数据库事务中检查账号画布数和结构化总字节，并以用户级行锁或原子记账保护跨画布并发；单文档大小不等于账号总量。
3. 多实例写在读取状态/回执前取得数据库协调锁；相同operationId同内容回放同回执，不同内容拒绝；冲突归类409，失败原子回滚。
4. 登录同一账号、进入相关画布可发现服务端 Agent 会话，分页恢复轮次/事件、SSE续接、跨端刷新和继续；不覆盖未发送草稿/未知提交身份。过期父轮续接在持久事务内拒绝。保留现有按画布入口及多会话，不迁移Agent记忆/压缩/长期偏好。
5. 素材本地保存后，项目关联/移动/分类意图持久化；断线、刷新、重新登录后幂等续做，按账号隔离，区分云端关联待同步。队列意图使用不复用的标识，服务端以项目版本条件写入防止旧请求晚到覆盖新意图；关联恢复不得回写旧缓存正文，永久阻塞须可识别并支持人工重试。
6. 本地非内联格式统一attachment+sandbox+nosniff；OSS浏览器字节继续不经平台转发。云端只有可保证附件响应的源站/CDN允许直连，否则明确拒绝。公开CDN下载必须声明/满足响应参数转发合同。保留S3显式path-style。
7. 展示/复制/浏览器处理的源站签名按窗口稳定且配置私有缓存；保持现有用途TTL、签名安全和前端账号隔离。
8. 文本作者字段节点租约获取/续期/确认保存后释放；所有文档写入验证证明，状态不泄漏token。租约不占用整画布，不挡任务进度回填。
9. 服务端状态汇总revision/epoch、租约、活跃Agent。统一事务提交后失效通知，断连走现有事件/快照恢复；presence临时光标/拖动不入业务文档。
10. 普通画布接入统一命令通路并保留草稿恢复；同节点无关字段允许安全合并，同字段过期意图拒绝；结构操作保留实体/关系基线。

## 实施边界
仅在隔离工作区本地实现和有限专项验证；不修改生产、不部署、不推送或合并main。复用现有Go/TS依赖和主题token。所有新增API同步OpenAPI/稳定service别名；不扩大architecture baseline。Agent记忆、compaction、长期偏好和harness内部会话算法不在范围。

## 验收
以跨协议同字段冲突、不同字段合并、双实例幂等、跨画布账号配额、跨设备目录与SSE恢复、未知提交身份、账号切换、断线关联重试、主动文件类型及CDN附件合同为主要行为验收；测试不连接生产，容器仅在确有需要且核实隔离后使用。保留未完成真实浏览器/厂商合同验收的明确说明。

## 实施决定

- 普通画布命令接入先归档未确认缓存，迁移只使用缓存原有的版本、epoch或已确认内容基线。作者草稿另外记录节点generation；无法证明旧草稿属于当前实体时供用户恢复，不自动赋予新身份。未确认请求始终保留首次wire与operationId。
- 命令软删除保留内部行、历史和回执；正常列表、计数、正文、同步状态与新租约按live epoch过滤。整画布恢复使用RestoreVersion并建立新epoch，既有delete_canvas不可普通Undo复活的边界保持。状态轮询使用一致只读事务，不争用账号写锁。
- 实时失效从基础数据库连接观察已提交的revision/epoch/eventSeq/deleted元组，避免根事务或保存点尚未提交时发布。Redis只协调临时设备与唤醒；WS不会确认持久保存，客户端继续用命令事件和快照补读。设备号不是权限凭据。
- 云端会话恢复只增加账号/画布目录、轮次分页和展示事件重放，沿用当前执行器、收费、审批及多Agent合同。素材关联恢复使用项目revision CAS与条件创建，不上传旧素材正文。
- 数据库迁移增加63节点租约和64实体代次；实时presence不增加业务表。部署须同步前后端和WS代理配置，真实浏览器、多设备与云厂商链路验收见待测试清单。
