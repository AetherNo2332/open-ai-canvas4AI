修复后的完整重跑累计 59 项通过，但多步撤销/重做场景因原定 120 秒总等待失败。只读追踪确认该运行在 3 次阶段 UPDATE 锁错误后通过租约恢复，自然完成全部 12 次工具调用（11 次完成、1 次预设重做分支拒绝），总耗时 207.36 秒；门控释放后的耗时约 154 秒。脱敏证据为 `.local/agent-parity-multi-step-timing.json` 及对应 backend/worker 日志。脚本据此仅调整终态等待：120 秒没有步骤或事件推进则失败，总时长固定上限 300 秒；健康和门控等待仍为 120 秒，API 错误处理不放宽。前述失败独立保留，不能算作最终连续验收通过；SQLite 暂态锁冲突仍可能增加恢复耗时。
