## 已实现的修复

1. **显式清空协议。** 能力字段增加 Resettable；仅白名单字段接受 null。可选字段删除，正文/提示词恢复空字符串；生成合同及其模型/选项镜像同步更新，避免清空后又被旧合同复活。富文本清空与新正文可同批提交。
2. **补齐真实编辑字段。** 工作流标题与受限标量参数、模板变量、素材分类进入声明合同；工作流数值清空删除字典键。旧背板封面只开放清空，未开放任意资源地址写入。
3. **替换上传闭环。** 提取并测试真实上传重置对象，freeResize 只用于图片。资源绑定由服务端清理旧复制、版本与批次来源；转换器仅认可相应绑定命令会清理的字段，不静默吞掉未知修改。
4. **分类异步写入。** 先完成素材处理，再应用绑定及分类；回执核对账号、最新请求和资源身份，避免旧请求覆盖新节点状态。
5. **保存状态与恢复。** 本地修改立即显示待保存；连续转换失败覆盖同一备份记录，并用版本号拒绝旧备份回执。导航前备份未入队编辑、确认日志已落盘；等待期间出现新修改则拒绝离开。关闭页面有未保存提示，账号/主机连接切换前保留本地编辑。
6. **其他入口。** starterMode 纳入共享文档读取与自动保存依赖；创建 Agent 入口的重试明确保存目标画布。
7. **保存完成后的状态收敛。** 真实上传验收发现，页面补全 `previsScenes: []` 后，结构比较仍把无命令差异认作未保存，导致云端已保存但顶部一直显示正在保存。改为在结构不同时检查实际命令差异；不支持的编辑仍保持未保存并进入错误及备份流程。
8. **同步状态浮层。** 保留现有皮肤和圆角，将密集按钮改为带图标的分组菜单，区分保存状态、编辑占用和操作。保留冲突恢复说明、确认步骤、错误信息与本地草稿入口。
