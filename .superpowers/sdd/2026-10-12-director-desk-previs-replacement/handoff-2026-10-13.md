## 6. 踩坑清单(本会话实证)

1. **/tmp 每 bash 调用全新** → 登录+探针同一个调用;跨调用带 cookie 必现假 401。
2. docker compose 必须 `HOME=/mnt/d/open-ai-canvas/.local/toolchain/dhomedir` 前缀。
3. bun test 单进程 → 测试桩全局泄漏是真实事故源:mini-DOM 桩曾导致 5 个 skills 用例失败 + detect-gpu(`navigator.userAgent` 解构炸)+ React `window.screen` 探测炸;**解法=仅缺失定义+afterAll 删除**(`setup-build-globals.ts` 可直接当模板;rAF 桩 no-op,立即回调会死循环)。
4. 本机 vite build 不可用(rolldown win32)→ 构建门只有 docker;bundle 探针可用 `docker build --target web-build -t 探针 -f Dockerfile .`(缓存热时约 5 分钟)。
5. **minified bundle 取证陷阱**:函数名被 mangle、define 常量折叠会把字样消灭——`__APP_RUNTIME__` 标识符=0 只能证明"被替换了",证明不了值是 cloud 还是 desktop;可靠判据=**同机制对照实验**(`__APP_VERSION__` 的版本字面量存在于 bundle,证明 define 链路有效)+ 最终由真实浏览器行为仲裁。
6. `up -d --build` 不清卷 → 验收脚本"首个用户注册"会撞旧账号;验收前先 `down -v`。
7. Go 基线 26 顶层失败是**存量**(A/B 名称集合相同),判定回归必须做 stash 对照,不能只看 fail 数。
8. 验收脚本里 python3 解析 JSON 依赖容器外 host 的 python3(本环境有)。
