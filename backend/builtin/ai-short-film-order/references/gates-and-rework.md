# 门禁与重做

## 交给用户确认前先自查

- 分场：每场都能接一句“因为上一场……”；每场让人物的处境变好或变坏；删掉这一场故事会不一样。做不到的场合并或删除，并说明原因。
- 剧本：场次和分场一一对应。没经用户同意，不增删场次，不把两场并成一场或把一场拆成两场，也不调换顺序。动作只写看得见、听得见、演得出来的，不写心理解释。
- 时长：中文自然台词每秒约 2.5–3 个字，再加上停顿和反应的时间。一镜里台词说不完就拆镜或延长，不靠加快语速。
- 分镜：每镜写清为什么动或为什么不动，运镜写明起点、终点和跟着谁。连续三镜景别、角度都相同又都不动时，提出调整建议，用户坚持就保留。每次切镜都要带来新的信息。
- 每镜的开头状态接上一镜的结尾：人物位置、朝向、手里的东西、伤势、服装、光线。

## 提问示例

只在需要用户拍板时提问。一次一个问题，给 2–6 个选项，标出推荐项。

- 入口：从一个想法开始／我有完整剧本／我有部分资料／只修几个镜头
- 视觉媒介：真人写实／三维动画／二维动画／你来定
- 故事方向：给 2–4 个不同走向，各用一句话说明
- 场次数：按推荐的 N 场／更少更紧凑／更多更细
- 超出硬性时长：延长时长／精简台词／调整各场时长
- 收费批次：提交这一批／先做一张试看／暂不生成
- 上游改动后：只重做受影响部分／从第 N 步整体重来／暂时只保留新版
- 看片后：都可以用／第 N 组要重做／我逐条说明

## 完整剧本接手

1. 剧本在画布节点里时，用 `canvas_read_content` 读到 `hasMore=false`，记下实际读到的范围。读不全要说明，不当作读完。
2. 列出：场次（地点、内外景、时间）、出场角色和状态变化、道具、场景、每场时长估算，以及剧本里判断不了的缺口。缺口只问会影响制作的。
3. 问一次是否保持剧本不变、只补制作资料。剧本没有场号时，先问能否加制作用编号，编号不写回原文。
4. 用户要改剧情时，回到第 4 步另出新版。接手过程本身不改原文。

## 改动影响

改动还是草稿时，下游照常有效。改动确认后，按下表找出受影响的部分，只重做这些：

| 改了什么 | 需要复核或重做 |
| --- | --- |
| 一句话故事或梗概 | 和改动有关的角色、分场、剧本，再逐级往下查 |
| 角色外观 | 该角色的三视图和角色卡，含该角色的首帧和视频 |
| 角色性格或说话方式 | 该角色的台词；三视图不受影响 |
| 某一场剧本 | 该场的分镜行、首帧和视频；新出现的角色、道具、场景补进资产清单 |
| 某个分镜行 | 该行的首帧、它所在的视频组，以及下一镜的开头状态 |
| 某张参考图 | 绑定它的分镜行，以及用过它的首帧和视频 |
| 某张首帧 | 用过它的视频 |
| 某段视频 | 剪辑清单里的这一段 |

- 旧版本保留，不删除；不再使用的素材可以归档。
- 在「制作进度」节点和答复里列出受影响的行和节点，也列出仍然有效的部分。
- 重做需要收费生成时，重新授权。
