# 参考图与绑定

剧本和分镜都确认后才做这一步。参考图跟着分镜走，分镜没用到的不做。

## 1. 列资产清单

用 `storyboard` 的 `read` 逐行读分镜，列出每行要用的资产：

| 资产 | 类型 | 用到的镜头 | 绑定用途 |
| --- | --- | --- | --- |
| 阿遥 | 角色 | 1、2、5 | character |
| 旧书店 | 场景 | 1–4 | environment |
| 铜钥匙 | 道具 | 3、4 | prop |

- 角色：出现在两个以上镜头，或观众需要认出身份的，做三视图并建角色卡。只出现一次的路人写在提示词里，不做。
- 道具：推动剧情、反复出现或被人物拿在手里操作的，单独做。
- 场景：反复出现，或人物在里面走动、前后镜方向要对得上的，做场景参考。
- 换装、受伤这类短期状态写进分镜行。长期出现的造型才另做一套，名称写成“角色名·造型名”。
- 先查画布上已有的角色卡和图片，能用就用，不重复生成。

把清单连同张数、模型和价格发给用户确认。用户已授权按推荐方案做完时，列出清单后按权限规则直接提交。只生成清单里的。

## 2. 三视图要求

所有参考图沿用第 1 步定下的视觉媒介和风格。

- 角色：一张图里并排画同一人物的正面、侧面、背面全身，三个视图大小一致，脚踩同一条线。中性站姿，双手空着，剧情要求手持的除外。干净的纯色背景，均匀的平光。三个视图里脸、发型、服装、体型完全一致，画面里没有其他人，也没有文字。脸上有疤痕、首饰等小细节时，可以另加一张脸部特写。
- 道具：正面、侧面，再加背面或顶面，干净背景。旁边放刻度尺或硬币、杯子这类常见物件作尺寸参照。各视图的材质、颜色和磨损一致。同一道具有完好、损坏等不同状态时分开生成。
- 场景：一张交代全貌的大全景，画出出入口、窗、主要陈设和主光源的位置；再加两个其他角度，或一张俯视平面图。几张图是同一空间、同一时间、同一光线。标题里注明「视觉参考」，并告诉用户它不是精确的空间结构。

可直接套用的提示词模板见「影策短剧制作工作流」。

## 3. 生成与验收

1. 用 `model_list`（mode=image）选模型，按清单逐张提交 `generate_media`，不必等上一张完成。等待期间先写角色设定文字。
2. 要建角色卡或判断画面时，才调用 `wait_generations`。
3. 逐张 `canvas_inspect_image`。角色：三个视图是不是同一个人、服装是否一致、手里有没有多余的东西、有没有多余人物或文字。道具：形状和尺寸参照是否清楚。场景：几张是否同一空间、同一光线。
4. 不合格的只重做那一张，重做算新的一批。合格的发给用户看，用户确认后才算定稿；用户事先授权按推荐方案做时，验收合格即可定稿。

## 4. 建角色卡

每个核心角色定稿后，用 `canvas_create_character` 打包：

- 只有一张三视图时传 `imageNodeId`，这张图同时作主图和三视图。
- 另有定妆主图时，传 `primaryImageNodeId` 和 `turnaroundImageNodeId`。两种方式不能混用。
- `definition` 只填剧本和图片能支撑的设定，未知项留空。
- 建完读回角色卡，确认 `character.resolvedImage` 和 `representations` 用的是这张三视图。

角色卡字段和版本维护见「影策短剧制作工作流」。

## 5. 绑定到分镜行

1. 用 `storyboard` 的 `read` 取最新的 `rowId` 和 `snapshotHash`；要看现有绑定时用 bindings 视图。
2. 用 `storyboard` 按清单绑定：角色卡用 `character`，场景图用 `environment`，道具图用 `prop`；服装、武器另有 `wardrobe`、`weapon`。
   - 在已有绑定上追加用 `add_assets`，它会保留原有角色。
   - 要整组替换才用 `set_assets`。它会清掉旧的资产和角色，提交前先把要保留的项合并进去。
   - 整部片都在同一场景时，可以用 `add_references` 设为共享引用。
3. 读回分镜，核对每行绑定和清单是否一致。后面的首帧和视频都从这些绑定取参考。
