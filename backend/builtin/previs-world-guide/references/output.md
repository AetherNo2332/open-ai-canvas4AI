# 预览、自检与交付

## 自检清单（每次写完）
1. 再次用 `director` 的 `read`，核对审批摘要里的每一项都已生效。
2. 时间：所有路径的 `end`、运镜段的 `start+duration`、动作的结束时间都不超过镜头 `duration`。
3. 空间：人物没有站进建筑或彼此重叠（看真实坐标，间距至少 0.5 米）；飞行高度与用户要求一致；站在台阶上的演员脚底高度没有被清零。
4. 路径：`scene.paths` 的标签、点数、长度与保存前一致；`objects[].motionPath` 与 `cameras[].motionPath` 的点和开始时间正确。
5. 镜头：摄影机 `target` 对着主体；跟拍、环绕的 `subjectId` 是正确的人物；`cameras[].moves` 的时间段在镜头内。
6. 有疑问的地方如实说明，例如「无法确认画面里人物是否被树挡住，建议预览」。

## 预览
- `director` 的 `preview` 只是请求浏览器录制白模视频，前提是用户已经打开世界引擎。
- 这个 action 没有录制完成的同步回执。不要说「我看了预览」；需要检查画面时请用户看一下。

## 保存与重开
- 保存后刷新或重开项目，再读同一场景，核对路径、运镜段、时间轴和镜头面板一致。
- 从时间轴删除一段后保存重开，确认删除已持久化，其他路径或运镜仍可播放。

## 交付给视频生成
- 世界引擎会自动把镜头编译成提示词，内容包括景别、运镜时间线、人物位移、路径运动、环境与光线，并把构图图和白膜视频作为参考。
- 用户要「生成视频」时，引导用户在世界引擎里回写构图或白膜，再用对应的视频节点生成。不要绕开世界引擎另写一套运镜描述。
